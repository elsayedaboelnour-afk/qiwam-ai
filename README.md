# قِوام | QIWAM AI
## تطبيق الفحص الوضعي الذكي

> قوامك الصحي يبدأ بالوعي

تطبيق ويب تفاعلي للفحص الوضعي الذكي باستخدام الذكاء الاصطناعي، مخصص لدول الخليج العربي وقطر.

### المميزات
- 🔬 6 وحدات فحص وضعي شاملة (الرأس والرقبة، الكتفان، الجذع، الحوض، الأطراف السفلية، المستوى السهمي)
- 🤖 محاكاة ذكية لتحليل نقاط الهيكل العظمي (Pose Estimation)
- 📊 لوحة نتائج تفصيلية مع مؤشرات القياس
- 🏃 مكتبة 15 تمريناً علاجياً باللغة العربية
- 👨‍⚕️ لوحة تحكم للأخصائيين الفيزيائيين
- 📄 تقرير PDF طبي باللغة العربية (RTL)
- 📈 مقارنة التقدم الزمني

### تجربة التطبيق
🌐 [افتح التطبيق مباشرة](https://elsayedaboelnour-afk.github.io/qiwam-ai/)

### التقنيات المستخدمة
- HTML5 / Tailwind CSS
- Chart.js (الرسوم البيانية)
- Canvas API (محاكاة Pose Estimation)
- Arabic RTL Support
- خطوط Cairo & Tajawal
